This repository contains code for a website whose goal is to test and evaluate the efficiency of Large Language Models as _(1)_ Replacement for discussion leads in
the context of socratic deliberation and _(2)_ Argument quality assessors in the context of the Pragma-Dialectical Model of argumentation. This web app was built to
simulate the efficiency of a multi-LLM deliberation platform, which was tested through data collection (stored in a private Google Drive folder) in the Prolific
platform. This is all with the goal of improving the quality of online deliberation, and promoting consensus within discussion through better informed arguments.
